# Japanese-Reading-Aide
Japanese Reading Aide is a web application designed to help Japanese language learners improve their reading comprehension and vocabulary. Users can analyze Japanese text, learn unfamiliar words, and review vocabulary using flashcards.

# Key Features
- Paste or upload Japanese text.
- Analyze Japanese vocabulary and view English definitions.
- Save readings for later review.
- Study vocabulary using flashcards.
- Track vocabulary coverage and learning progress.
- Switch between light and dark mode.

# Project Pages
- Home: Introduction to the website.
- Analyze: Upload or paste Japanese text.
- Results: View vocabulary analysis.
- Study: Review vocabulary with flashcards.
- My Readings: Access saved readings.
- About: Learn more about the project.
